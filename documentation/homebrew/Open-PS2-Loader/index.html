--- layout: docs-homebrew title: >- Open PS2 Loader subtitle: >- Open PS2 Loader (OPL) is a 100% Open source game and application loader for the PS2 and PS3 units. It supports five categories of devices: USB mass storage devices, MX4SIO (SD card connected to memory card port via adapter), iLink (SBP2 compliant storage devices via IEE1394), SMBv1 shares and the PlayStation 2 HDD unit. USB/SMB/MX4SIO/iLink support both USBExtreme and *.ISO formats while PS2 HDD supports HDLoader format, all devices also support ZSO format (compressed ISO). It's now the most compatible homebrew loader. image: https://rggames.com.br/wp-content/uploads/2024/06/opl.jpg thumbnail: https://rggames.com.br/wp-content/uploads/2024/06/opl.jpg category: docs last_updated: 2025/03/08 project_status: Unknown # authors: korax # factcheck: NA ---
